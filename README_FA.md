# NetLab Academy — اندروید

این بسته **کد منبع اندروید** است، نه APK آماده. فایل‌های وب، کتاب و فونت داخل برنامه بسته‌بندی شده‌اند.

## ساخت بدون نصب نرم‌افزار روی رایانه
۱. در GitHub یک مخزن جدید به نام `NetLabAcademy-Android` بسازید. فایل‌های این ZIP را با حفظ ساختار پوشه‌ها در ریشه مخزن بارگذاری کنید.
۲. فایل `.github/workflows/build-android.yml` را نیز در مسیر دقیق خودش بسازید (اگر پوشه مخفی آپلود نشد از Add file → Create new file استفاده کنید).
۳. به Actions → Build Android APK → Run workflow بروید.
۴. پس از تیک سبز، در Artifacts فایل `NetLabAcademy-Android-APK` را دانلود و استخراج کنید. فایل `app-debug.apk` را به گروه بفرستید.

## ملاحظات
- نسخه Debug امضای توسعه دارد و برای تست و توزیع محدود است؛ برای انتشار در مارکت، نسخه Release با امضای دائمی لازم است.
- Android 6.0 و بالاتر هدف‌گذاری شده است؛ روی همه گوشی‌ها تست نشده است.
- PDF با نمایشگر بومی صفحات اندروید باز می‌شود و جست‌وجو در رابط اصلی فقط نتیجه پودمان و شماره صفحه را نشان می‌دهد.
- خروجی PNG طرح درس در WebView اندروید **هنوز نیازمند اتصال به ذخیره‌سازی بومی** است؛ ممکن است دانلود آن کار نکند. سایر امکانات نیز باید روی دستگاه واقعی آزموده شوند.
- این پروژه فاقد تأیید تست ساخت APK و تست روی گوشی است؛ ساخت موفق تضمین نمی‌شود.
