NetLab Academy - Android PWA

این بسته APK نیست. برای نصب، محتوای پوشه را در یک میزبان HTTPS مثل GitHub Pages قرار دهید. سپس در Chrome اندروید آدرس سایت را باز کنید و Install app یا Add to Home screen را انتخاب کنید. برای استفاده آفلاین، یک بار اجازه دهید تمام فایل‌ها از جمله PDF بارگیری و ذخیره شوند. باز کردن مستقیم index.html از فایل منیجر امکان نصب PWA و سرویس‌ورکر را فراهم نمی‌کند.

GitHub Pages: Settings > Pages > Deploy from a branch > main > /root. فایل‌های داخل این بسته باید در ریشه شاخه منتشرشده قرار بگیرند.

سازگاری با همه نسخه‌های اندروید تضمین نمی‌شود؛ به مرورگر دارای پشتیبانی PWA و Service Worker نیاز است.
